# 测试小站合集

四个自建的在线测试站点，同域部署在 `dream.webtrn.cn` 下，各站独立数据库、独立后台，互不影响。

技术栈统一为 Next.js + Prisma + SQLite，服务端渲染，移动端优先，已适配老旧 iOS / Safari 12。

## 站点一览

| 站点 | 主题 | 链接 | 题量 | 门禁 |
| --- | --- | --- | --- | --- |
| 梦境人格测试 | 16 型梦境人格 | https://dream.webtrn.cn | 32 题 | 需访问口令 |
| 鬼格测试 | 16 型鬼格（玄学风） | https://dream.webtrn.cn/ghost | 32 题 | 需访问口令 |
| 命定城市测试 | 40 座城市择城 | https://dream.webtrn.cn/city | 八字 + 六维问卷 | 需访问口令 |
| 思维同道 | 49 位历史人物思维匹配 | https://dream.webtrn.cn/mind | 24 题 | 免费开放 |

> 标注「需访问口令」的站点为付费门禁，口令不在此仓库公开，需另行获取。「思维同道」可直接打开使用。

## 各站介绍

### 梦境人格测试

基于原创四维人格体系，通过 32 道四选一题目，生成专属于你的梦境人格画像与深度解析。

- 链接：<https://dream.webtrn.cn>
- 四个维度组合出 16 种人格类型，每型配独立立绘与长文解析
- 支持注册账号、保存历史测试记录

### 鬼格测试

基于原创四维人格体系，通过 32 道四选一题目，生成专属于你的鬼格画像与深度解析。玄学幽冥主题。

- 链接：<https://dream.webtrn.cn/ghost>
- 四维八极：魂相（游魂／定魄）、阴感（通冥／明鉴）、情执（痴念／忘川）、业行（随缘／争渡）
- 组合出 16 种鬼格，各配国风立绘

### 命定城市测试

结合八字排盘与六维生活问卷，从 40 座中国城市里算出与你最相合的那一座，附五行方位解析与备选城市。

- 链接：<https://dream.webtrn.cn/city>
- 八字排盘定五行方位，六维问卷校准生活偏好
- 输出首选城市 + 备选城市清单

### 思维同道

二十四问量出你的六维思维方式，从四十九位历史人物中找出与你想事路数最像的那一位，附思维侧写、招牌方法与原话出处。不必填生辰，免费。

- 链接：<https://dream.webtrn.cn/mind>
- 六维思维模型，24 题即可完成
- 每位人物配思维侧写、招牌方法与原始出处引文
- 无需登录、无需口令，直接开始

## 在线展示页

仓库内 `index.html` 是一个卡片式导航页，纯静态、无依赖，可直接开启 GitHub Pages 发布。

开启方式：仓库 **Settings → Pages → Source** 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后等一两分钟即可访问：

```
https://zhui111.github.io/test-games/
```

## 仓库结构

```
test-games/
├── README.md      本说明（GitHub 首页直接渲染）
├── index.html     卡片式导航页（可开 Pages）
└── .gitignore     排除 .env / *.db / 密钥等敏感文件
```

本仓库只包含说明与导航页，不含任何站点源码、数据库、访问口令或 API 密钥。
